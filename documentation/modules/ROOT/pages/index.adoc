= Groengascapaciteitskaart

To address current and future bottlenecks in the grid capacity for green gas,
NDG-Green Gas has developed the Green Gas Grid Capacity Program. This program
focuses on providing insight into the available transport capacity of the gas
grid for all grid operators in the Netherlands.
